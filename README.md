POLÍTICA DE PRIVACIDADE E TERMOS DE USO

Este aplicativo utiliza a API do Instagram Graph para fornecer suas funcionalidades.

1. Coleta de Dados
Coletamos apenas as informações públicas do perfil do usuário do Instagram e suas mídias (fotos e vídeos), estritamente conforme autorizado pelo usuário por meio do fluxo de login da Meta.

2. Uso das Informações
Os dados coletados são utilizados exclusivamente para o funcionamento interno do aplicativo (como exibição de mídias ou análise de dados solicitada pelo próprio usuário). Não compartilhamos, vendemos ou utilizamos esses dados para outros fins.

3. Exclusão de Dados
O usuário pode revogar o acesso do aplicativo a qualquer momento diretamente nas configurações de sua conta do Instagram. Para solicitar a exclusão definitiva de qualquer dado armazenado em nossos servidores, entre em contato pelo e-mail: [SEU_EMAIL_AQUI].
